# weekly-ai-leadership-news

기업교육(HRD) 담당자를 위한 **AI 리더십 주간 뉴스레터**를 대신 만들어 주는 Claude 스킬입니다.
매주 AI 리더십 관련 글로벌·국내 소식을 검색하고, 본문을 확인해 고른 기사로 읽기 편한 HTML 뉴스레터를 만듭니다.

## 이 스킬이 대신하는 업무

| 사람이 하던 일 | 스킬이 하는 일 |
|---|---|
| 주제별 뉴스·보고서 검색 | 리더 AI 역량, 조직 AI 도입, 기업교육·HRD, AI 거버넌스, 컨설팅사 보고서, 국내 사례를 병렬 검색 |
| 기사 선별 | 관련성·영향도·신선도·신뢰도 4항목 점수제로 선별(5점 이상). 지난 호와 중복되는 기사는 제외 |
| 사실 확인 | 기사 본문을 열어 발행일과 수치를 확인. 확인 못 하면 "(본문 미확인)"으로 표시 |
| 뉴스레터 작성 | 후킹 문구, 핵심 3줄, 기사 카드, 교육 적용 포인트, 경영진 보고용 한 문장, 교육 설계 아이디어까지 작성 |
| 편집 검토 | 블랙(기획)·레드(AI리더십 연관성)·골드(교육담당자 유용성)·퍼플(후킹·가독성)·화이트(색 편안함) 5개 관점으로 3회 검토. 각 9.5점/10점 이상 목표 |

## 호출하는 말

Claude Code에서 아래처럼 말하면 호출됩니다.

- "AI 리더십 주간 뉴스레터 만들어줘"
- "이번 주 AI 리더십 글로벌 트렌드 정리해줘"
- "weekly-ai-leadership-news 실행해줘"
- 정기 실행: 스케줄 작업으로 등록해 매주 월요일 오전 7시에 자동 실행(아래 참고)

## 설치

1. 저장소를 내려받습니다.

   ```bash
   git clone https://github.com/hbhrd/news-clipping.git
   ```

2. 스킬 폴더를 Claude Code 스킬 디렉터리에 복사합니다.

   - 모든 프로젝트에서 사용: `~/.claude/skills/weekly-ai-leadership-news/`
   - 한 프로젝트에서만 사용: `<프로젝트>/.claude/skills/weekly-ai-leadership-news/`

   ```bash
   cp -r news-clipping/skills/weekly-ai-leadership-news ~/.claude/skills/
   ```

3. (선택) 매주 자동 실행: Claude 앱의 스케줄 기능(예: `/schedule`)으로 이 스킬을 매주 월요일 오전 7시에 실행하도록 등록합니다. 앱이 켜져 있을 때 실행되고, 꺼져 있으면 다음 실행 때 돕니다.

필요한 도구는 웹 검색(WebSearch)과 웹 페이지 열람(WebFetch)입니다.

## 결과물

작업 폴더의 `ai-leadership/YYYY-MM-DD-newsletter.html`로 저장되는 단일 HTML 파일입니다. 샘플은 [`examples/sample-newsletter.html`](examples/sample-newsletter.html)에서 볼 수 있습니다.

구성 순서:

1. 마스트헤드: 제목, Vol.N, 날짜
2. 후킹 문구: 이번 주 가장 강한 숫자 1개를 형광 하이라이트로 강조
3. 이번 주 핵심 3줄
4. 글로벌 트렌드: 기사 카드(수치 타일, 요약 2문장, 교육 적용 포인트)
5. 국내 동향
6. 숫자로 보는 신호
7. 경영진 보고용 한 문장
8. 이번 주 교육 설계 아이디어 3개(대상·소요·근거)
9. 일정 참고
10. 수집 기간, 한계사항, 출처 링크

디자인: 크림·세이지 그린·연노랑의 편안한 색, 큰 글씨의 후킹 문구, 모바일 대응, 다크 모드 지원.
채팅에는 웹 주소(게시한 경우), 핵심 3줄, 라운드별 5색 점수표, 한계사항이 함께 보고됩니다.

## 알아 둘 점

- 5색 점수는 스킬이 역할을 나눠 매기는 자체 점검이며, 실제 독자 반응과는 다를 수 있습니다.
- 기사 링크와 수치는 검색과 본문 열람에서 확인된 것만 씁니다. 의견·투자 조언은 쓰지 않습니다.
- 이메일·메신저 발송은 하지 않습니다.
- 웹 게시는 선택 사항이며, 게시 주소를 직접 지정한 경우에만 합니다.
